从立方体到风格化场景：零基础第3期学员的成长全记录
第三期风格化场景特训营开营那天，四十多个学员的软件里同时新建出一个灰扑扑的立方体。这群人的背景五花八门：有朝九晚五的行政专员，有开了三年奶茶店的个体户，还有刚退休的中学老师，几乎没人接触过三维创作，连透视的基本概念都讲不清楚。没人能想到，六周之后，这些连基础操作都陌生的普通人，能各自交出一套完整的、带着个人生活温度的风格化场景作品。

第一周的作业简单到让人意外：用立方体搭出十个不同的日常物体。很多人刚上手就犯了难，对着屏幕上的六面体发呆，想不通方方正正的形状怎么能变成桌子、椅子、收纳箱。有个学员做到第八个物体时彻底卡壳，在群里问老师“除了方盒子，立方体还能变出什么”，老师的回答点醒了所有人：“所有复杂造型拆到最后都是立方体，你现在不是在搭积木，是在练拆解世界的眼光。”那天之后，学员们走在路上都忍不住盯着身边的物件看：便利店的货架是拉长的立方体，路边的邮筒是削掉边角的立方体，连家里的冰箱，本质上也是一个带门的立方体。

第二周的训练开始延伸，课程把圆柱、球体等基础形体也纳入进来，作业要求变成“搭建一个有生活气息的小角落”。大家不再满足于规整的几何体，开始往场景里塞进自己熟悉的生活细节：有人做了自己工位的一角，反复调整十七遍马克杯把手的弧度，把多肉的叶片捏出被晒软的自然弧度；有人还原了自己奶茶店的操作台，连杯架上贴的小贴纸都做了出来。老师在作业点评里特意圈出了这些细碎的细节，告诉大家建模从来不是堆形状，而是把你眼睛里看到的真实世界，一点点翻译给软件听。

到第四周，最终的风格化场景作业正式发布，要求学员做一个自己理想中的小店，风格完全不限。之前总怕自己做不好的学员，第一反应就想到了藏在自己记忆里的那个场景：有人选了童年时外婆家楼下的面包房，有人做了上学时总去蹭书的旧书店，还有人还原了自己一直想开的小花店。大家把前几周练熟的形体拆解方法全部用上：立方体拼接成暖黄色的墙体，圆柱搭出带条纹的遮阳棚，压扁的球体一个个叠成刚出炉的面包，连窗台上的小摆件都用最基础的形体慢慢调整出来。

结课那天，所有人的作品铺满了展示墙，没有哪一个是完美的：面包房的遮阳棚条纹粗细不均，旧书店的书架边缘还留着一点没修平的棱角，但每一幅图都透着一股笨拙又鲜活的可爱。学员们在分享会上说的最多的一句话是：以前总觉得做3D场景是美术生的专利，现在才明白，只要把一个大目标拆成无数个小立方体，一点点啃，普通人也能搭出属于自己的小世界。

现在第三期的学员群还没解散，经常有人把新做的场景发进来：第一周连立方体都摆不正的奶茶店老板，做出了一整间飘着热气的冬日热饮店；之前完全零基础的行政专员，又完成了一个摆满旧物件的复古书房。从第一个灰扑扑的方块，到一个完整的、带着温度的风格化场景，中间隔着的不过是六周时间、二十次作业，和无数个对着屏幕慢慢调整形状的夜晚。很多人总觉得零基础学创作是遥不可及的事，但这群学员的经历恰恰证明：你不需要一开始就做出完美的作品，只要敢从第一个简单的立方体开始，一步一步往前走，普通人也能亲手搭建出属于自己的虚拟小世界。
